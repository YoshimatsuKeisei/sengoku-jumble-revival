# Recovered SWF source anomalies / version-sensitive points

## pstch technique-slot anomalies

### 徳川家康軍 (efm126)
Recovered v144 bytecode performs:
1. `m30` 徳川家康 `ac=24` (治癒)
2. writes `m31` 本多忠勝 stats/ss
3. then writes **`m30.ac=22` (豪傑)** instead of `m31.ac`

Therefore final source behavior appears to overwrite 家康's technique to 豪傑 and leaves 本多忠勝's technique as the value previously generated by `chpr()`. This package does not silently correct the apparent typo.

### 裏戦国 (efm129)
For `m50` 筧十蔵, recovered bytecode assigns name/stats/ss, then writes **`m51.ac=5`** rather than `m50.ac`. Thus 筧十蔵 lacks a direct `pstch` technique assignment and retains its pre-existing `chpr()` technique.

## Archive/wiki differences
Community tables are useful cross-checks but are observational and may represent another revision or corrected expectations. Recovered `sgjbgm.swf` v144 is treated as primary source for implementation.
