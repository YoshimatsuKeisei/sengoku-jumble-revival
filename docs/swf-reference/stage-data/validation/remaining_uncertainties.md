# Remaining uncertainties / scope boundaries

## Formation 130
`fmdt()` contains formation ID 130, but normal `mpcm()` map-stage selection did not expose a matching `efm=130` branch in the recovered v144 SWF. It is preserved as source data but its intended live-game use is unresolved.

## Generic special-ability (`ss`, `sN`) normalization
`chpr()` contains generic special-ability generation and all raw AVM1 evidence is retained in `raw/chpr_decompiled_relevant.txt`. This package does **not** yet normalize every `sN` code to its Japanese special-ability name and exact final occurrence probability. Famous soldiers preserve the raw `ss` strings.

## Technique counts per stage
For generic slots, technique is generated by `chpr()` at battle setup. Therefore a named stage does not normally have a deterministic count such as “砲撃 exactly N”. `named_stage_technique_expectations.*` reports expected counts, while direct famous-unit assignments are fixed.

## `fmdat == "n"` sentinel path
Several rare-technique gates are suppressed while `fmdat == "n"`. The package includes both active-`fmdat` and sentinel-path technique distributions. Do not blindly use only one table without matching the remake's save/battle setup semantics.

## Original-source assignment anomalies
See `source_anomalies.md`. The package deliberately preserves the recovered v144 bytecode behavior instead of silently correcting apparent author typos.
