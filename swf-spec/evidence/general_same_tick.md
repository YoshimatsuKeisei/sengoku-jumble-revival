# Same-tick general command evidence

Prior SWF analysis strongly suggests that overlapping general commands arriving at the same logical instant are observed by a recipient as one forced activation. Different legitimate triggers at different times may still produce consecutive attacks, and DOUBLE_SPECIAL remains a separate ability.

The present runtime iterates generals independently and each GENERAL_COMMAND can call the forced-technique callback for the same AI recipient during one update. No same-update recipient dedupe is visible in this path. Because the SWF conclusion is not yet promoted to confirmed evidence, this rule remains inferred and is diagnostic only.
